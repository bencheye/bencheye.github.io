最近接着读《周易》的晋卦与明夷卦。这两卦紧挨着，卦体上下颠倒，形成一组很鲜明的画面：**晋是明出地上，明夷是明入地中。**

同一个“明”，随着时势改变位置，也改变了行动方式。光明升起，可以向前；光明被遮蔽，则需要保存自己，等待适宜的时机。

这篇笔记沿用“**卦象—字义—六爻时间轴—时、位、变、中—现实应用**”的思路。对爻辞的解释参考传统注疏；联系现实的部分，是我自己的理解。

## 一、两卦的整体气象：明出地上，明入地中

| | 晋卦（火地晋，䷢） | 明夷卦（地火明夷，䷣） |
| --- | --- | --- |
| 卦体 | 上离下坤 | 上坤下离 |
| 卦象 | 明出地上 | 明入地中 |
| 气象 | 光明上升，事物显达 | 光明被掩，环境昏暗 |
| 卦辞 | 康侯用锡马蕃庶，昼日三接 | 利艰贞 |
| 《象传》 | 君子以自昭明德 | 君子以莅众，用晦而明 |
| 行动方向 | 顺势进取，修明自身 | 隐藏锋芒，艰难守正 |

**晋，重在顺时而进；明夷，重在处暗而守明。**

《序卦传》说：“晋者，进也。进必有所伤，故受之以明夷。”进取会遇到阻力，也可能由于进得太过而受到伤害。晋与明夷相接，正好提醒人留意进取的边界。

两卦又互为综卦。日出与日入可以用来体会事物运行的周期，但具体的人事局面仍要看所在阶段，不能把卦序当作必然发生的命运。

## 二、关键字义：从动作理解卦名

**晋（晉）**：《说文解字》释为“进也。日出万物进。从日，从臸。”这里把日出、万物向前生长联系起来。晋的核心动作是**向上、向前，逐渐显达**。

**夷**：《周易》传统注解常训为“伤”，所以“明夷”有光明受伤、受遮蔽之义。夷字本身的早期义项较复杂，不宜把“伤”直接认定为它唯一的造字本义。

**晦**：《说文解字》释为“月尽也”，原指月末光暗之时；引申为幽暗、隐藏。用在明夷中，既可以体会环境的昏暗，也可以体会有意识地收敛外在光芒。

**明**：既是卦象中的日光，也可引申为辨别是非、洞察事理的能力。晋的“自昭明德”侧重修明与彰显；明夷的“用晦而明”侧重保存和运用内在的明。

“明”能否保存，比一时处于“晋”还是“明夷”更值得留意。

## 三、晋卦：进取的六个阶段

> 晋：康侯用锡马蕃庶，昼日三接。
>
> 《彖》曰：晋，进也。明出地上，顺而丽乎大明，柔进而上行。
>
> 《象》曰：明出地上，晋。君子以自昭明德。

“锡”通赐，“蕃庶”指众多。“康侯”获得赏赐，白昼屡受接见，描绘的是得到认可、获得支持的进取局面。

但六爻说明：**处在上升的大趋势里，各个位置仍有不同的风险。**

| 时位 | 爻辞 | 处境与应对 |
| --- | --- | --- |
| **初六** | 晋如摧如，贞吉。罔孚，裕无咎。 | **起步受阻，尚未得信。** 保持原则，宽裕自处，不急着证明自己。 |
| **六二** | 晋如愁如，贞吉。受兹介福，于其王母。 | **前行有忧，居中守正。** 眼前虽不顺，仍可凭中正获得后续助力。 |
| **六三** | 众允，悔亡。 | **获得众人信任。** 进取开始有共同意志与支持，原来的隐患随之减轻。 |
| **九四** | 晋如鼫鼠，贞厉。 | **身在高位，贪进而畏。** 位置与行为失调，继续如此将有危险。 |
| **六五** | 悔亡，**失得勿恤**，往吉，无不利。（主爻） | **居中而主事。** 放下对一时得失的计较，把握整体方向，继续前行。 |
| **上九** | 晋其角，维用伐邑，厉吉无咎，贞吝。 | **进到极处。** 收敛对外扩张的冲动，转向整治内部；继续强进易困。 |

### 初六至六三：有进取之势，还要有承载之基

初六“晋如摧如”，想前进却受到压抑；“罔孚”是尚未取得信任。“裕无咎”提示人在初进时要有余裕，允许信任慢慢形成。

六二“晋如愁如”，进取伴随忧虑。六二居中得正，《象传》以“中正”解释其受福：守住行为准则，未必要在当下立即得到回报。

六三“众允，悔亡”。“允”有信从、认可之意。个人的愿望逐渐成为众人共同认可的方向，前进便获得支持。

这三爻构成一个过程：**受阻守正 → 忧中积累 → 众人信从。**

### 九四至上九：进得越高，越要辨认边界

九四说“晋如鼫鼠，贞厉”。传统注解常以鼫鼠贪而畏人说明其处境；《象传》点出“位不当也”。已经进到较高的位置，却仍以贪求、畏惧的方式行事，难以安处其位。

六五“悔亡，失得勿恤”。身居主事之位，容易被一次得失扰乱判断。六五虽阴居阳位，却得中；此时更需要关注大方向，少为局部成败所困。

上九“晋其角”，进取发展到角尖。“维用伐邑”可以理解为把力量用于整治自身范围内的问题。《象传》说“道未光也”，提示这种强硬方式依然有限。“贞吝”则提醒：在进取已极时继续固守强进，容易陷入窘境。

晋卦的六爻主线可以概括为：

> **受阻 → 守正 → 得众 → 戒贪 → 忘得失 → 知止**

上升时真正需要防范的，是把前一阶段有效的做法，机械地延续到下一阶段。

## 四、明夷卦：身处黑暗的六种应对

> 明夷：利艰贞。
>
> 《彖》曰：明入地中，明夷。内文明而外柔顺，以蒙大难。
>
> 《象》曰：明入地中，明夷。君子以莅众，用晦而明。

“利艰贞”，意味着艰难处境下仍宜守正。

“莅众”是临于众人之上、治理众人；“用晦而明”则提示治理者可以内心明察、外在宽厚，避免处处炫示自己的洞察。即使身处昏暗之世，内在的明也仍可保存。

| 时位 | 爻辞 | 处境与应对 |
| --- | --- | --- |
| **初九** | 明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言。 | **察觉危险，及时离开。** 即使暂时困顿、遭人非议，也可见几而行。 |
| **六二** | 明夷，夷于左股，用拯马壮，吉。 | **伤害已经发生。** 借助外力自救，防止伤势继续加深。 |
| **九三** | 明夷于南狩，得其大首，不可疾贞。 | **有力量除去主要祸患。** 行动可以果断，后续纠正积弊仍须渐进。 |
| **六四** | 入于左腹，获明夷之心，于出门庭。 | **接近昏暗的内部。** 察知其心意与风险，适时出门避难。 |
| **六五** | 箕子之明夷，利贞。 | **身近至暗，难以脱身。** 外晦内明，忍辱守正，保存内在的道。 |
| **上六** | 不明晦，初登于天，后入于地。 | **昏暗发展到极点。** 居高而失则，终于由盛转衰。 |

### 初九、六二：危险有先兆，也有伤害已经发生的时候

初九“明夷于飞，垂其翼”，像鸟垂翼而飞，谨慎离开危险之地。“三日不食”说明退避也要付出代价；“主人有言”说明这种选择可能不被他人理解。

初九重在**见几而作**：危险尚在萌芽时，已经可以调整方向。

六二“夷于左股”，腿部受到伤害，行动受限。“用拯马壮”则是借助强健马匹自救。此时重点在**止损与求援**，不必执着于独自承受。

### 九三、六四：能除害，也要懂得识害与渐治

九三“明夷于南狩，得其大首”，有向明除暗、去其首恶的意味；但紧接着说“不可疾贞”。

王弼注解的要点是：元恶虽然已经去除，众人的旧习却形成已久，教化与整治需要时间。**除弊可以果断，革新需要循序渐进。**

六四“入于左腹，获明夷之心，于出门庭”。“左腹”取幽隐、内部之象；“获明夷之心”，可理解为察知昏暗者的心意。知道局势如何运作，才有机会选择恰当的退避方式。

九三与六四提示两种不同能力：**有力量时可以除暗；置身复杂局面时，需要识局、识人、识退路。**

### 六五、上六：外晦内明，与居高失明

六五“箕子之明夷，利贞”。相传箕子身处商纣王暴政之中，佯狂为奴，保存自身与原则。《象传》说：

> 箕子之贞，明不可息也。

身处最难的环境，仍能守住内在的明。

上六“不明晦，初登于天，后入于地”。《象传》解释“后入于地，失则也”。居于高位而失去法则，最终由明转晦、由盛转衰。

六五与上六构成对照：**六五身处暗境，心中有明；上六身居高处，已经失明。** 一时的地位无法决定一个人是否真正合于道。

明夷卦的六爻可以概括为：

> **察险而退 → 受伤自救 → 除害渐治 → 察情而出 → 晦藏守正 → 失则而坠**

六爻对应的是不同的处境与应对方式，也可以作为观察一段局势如何恶化、变化的时间轴。

## 五、几个重要占辞：悔亡、贞厉、贞吝

读两卦时，几个反复出现的字值得分辨。

| 词语 | 基本含义 | 放在卦爻中的提醒 |
| --- | --- | --- |
| **悔亡** | 悔恨或引发悔恨的因素消除 | 处境有机会通过行为调整而改善 |
| **无咎** | 没有灾咎、可免过失 | 行为虽可能艰难，仍可免于咎害 |
| **厉** | 危险、危厉 | 需要认识风险，并不等于灾祸必然发生 |
| **吝** | 困窘、遗憾 | 行动失当，容易陷入难堪 |
| **贞厉** | 传统义理常释为固守则有危 | 晋九四尤须留意位置与行为是否相称 |
| **贞吝** | 传统义理常释为固守则困 | 晋上九尤须留意进取是否已经过度 |

“贞”在早期占辞中首先与占问有关，后来也经常被解释为正、守正。因此，“贞厉”“贞吝”还可以从“占问得危险、困窘之兆”理解。将它们读成“固守当前做法会有危险”，是一种结合具体爻位的义理解释，不能套用于所有卦爻。

“悔亡”也并不意味着一切都已经完美。它说明可悔的因素消退，仍需要观察后续的时位变化。

## 六、知其白，守其黑：晋与明夷的共同内核

《道德经》第二十八章：

> 知其白，守其黑，为天下式。  
> 为天下式，常德不忒，复归于无极。

**知白**，是能够看清事物的道理；**守黑**，是知道何时收敛、谦下，不以彰显自己为目的。

这与《明夷·象传》的“用晦而明”相通。

但守黑也需要判断时势。晋的“自昭明德”提醒人，时势适宜时应当发挥才能、承担事务；明夷的“晦其明”提醒人，环境昏暗时可以藏锋、守正、保存力量。

自然有昼夜、月有朔望晦，人的处境也会出现显与隐、进与退。这样的循环并不等于每次简单重复：环境在变，所处位置和拥有的能力也在变。

**在晋时能进，在明夷时能藏；外在随时而变，内在守明不失。**

## 七、从“变、时、位、中”决定怎样行动

| 判断角度 | 需要问自己的问题 | 对应的爻义 |
| --- | --- | --- |
| **时** | 当前在上升、受阻、危险初现，还是黑暗已深？ | 晋初六宜宽裕；明夷初九宜见机而退 |
| **位** | 自己有没有足够的能力、支持和行动空间？ | 晋九四“位不当”；明夷六五近暗而难退 |
| **变** | 原来的方法还适用于现在吗？局势正在往哪里走？ | 晋上九应知止；明夷九三除害后须渐治 |
| **中** | 能否不被恐惧、得失或一时情绪牵动？ | 晋六五勿恤得失；明夷六二顺以则 |

放到现实中，可以形成几条很具体的判断：

**尚未获得信任时，学晋初六。** 保持原则，积累能力与信用，不急于争取一时认可。

**条件已经成熟时，学晋六三、六五。** 借助共同的支持前进，并把注意力放在长期方向上。

**已经进到高处时，戒晋九四、上九。** 检查自己的位置、能力与行为是否匹配；需要时把精力转向内部整治。

**环境开始失序时，学明夷初九。** 提前辨认征兆，保留离开的选择，即使他人未必理解。

**伤害已经出现时，学明夷六二。** 借助可用资源及时止损，不把硬撑当作唯一选择。

**有机会纠正局面时，学明夷九三。** 去除关键障碍，同时允许结构、习惯和关系逐步恢复。

**身处难以离开的困境时，学明夷六五。** 收敛外在表现，守住判断力与内心原则，保存未来的行动能力。

## 八、结语：明与晦有时，进与退有度

晋卦提醒我：**顺势而进，也要分清初进、得众、居高与进极。**

明夷卦提醒我：**处于逆势，也要分清可退、受伤、可除害、须隐忍等不同处境。**

所谓“亦龙亦蛇”，就是根据时势与自身之位改变行动方式：能进时进，宜退时退，须藏时藏。决定这些选择的，是对局势的判断，以及有没有守住内在的明。

> **明可以出地上，也可以入地中。处世之道，在于知时、知位、知变，而不失其明。**
